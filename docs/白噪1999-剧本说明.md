# 《白噪 · 1999 蓝湾镇回声事件》剧本设计与说明

一个大型原创 ARG：**53 个页面、8 类拟真界面、6 个结局**。
核心机制：**结局不取决于你点了哪个选项，而取决于你在整台电脑里真正挖到了哪几条线索。**

## 一、导入方式（30 秒）

1. 启动编辑器：项目目录里运行 `npm run dev`（或双击 `一键启动-Windows.bat`）。
2. 浏览器打开 `http://localhost:5173/`。
3. 点右上角「导入」，选择本目录 `examples/白噪1999-蓝湾镇回声事件.arg-blueprint.json`。
4. 点「自检」应为 0 错误 0 警告；点「预览运行」即可从「沈砚遗留的主机」开始游玩。
5. 想发布给别人：点「导出 ZIP」，得到纯静态 HTML，扔到任意静态托管即可。

> 同目录的 `build-blueprint.mjs` 是生成脚本。想改文案 / 加页面 / 调结局门槛，改完运行 `node build-blueprint.mjs` 会重新生成蓝图并自动自检。

## 二、故事梗概

2003 年冬。你是声音修复师 **沈知微**。哥哥 **沈砚** 是沿海小镇「蓝湾」深夜电台 FM99.4《潮声》主持人，2000 年 3 月 14 日「出海遇难、尸骨无存」。你收到他遗留的旧主机和一封信。

真相：广播站总工程师 **柯振** 与「瀚洋集团」董事长 **韩启昌** 合作，用深夜广播循环植入 **4.5Hz 次声波（"白噪"）**，经由民间组织 **听潮会** 把孤儿、康复者、负债工「招募—镇静—引渡」，在暴风雨夜送上「瀚洋 7 号」，对外称海难。沈砚察觉后私录最后一期《潮声·第九夜》，因此被列入名单灭口。

## 三、页面结构（53 页）

- **枢纽**：桌面、加密聊天、千禧搜索、蓝湾潮声论坛(BBS)、镇档案馆(目录)、维基百科(枢纽)、3 处密码锁、2 个文件柜。
- **线索页**：新闻 8 篇、论坛帖 8 个、维基词条 5 个、卷宗/日记/录音稿/名单/监控等 12+ 页、结局 6 页。
- 每类拟真界面都用到了：桌面图标、搜索关键词命中、BBS 热帖、匿名聊天、密码锁（后台 / BIOS）、文件夹、CRT 监控、杂志/卷宗/日记/黑客数据流版式、以及报纸头版 / 结案书 / CRT 黑屏三种结局版式。

## 四、三把密码（都藏在可发现的线索里）

| 锁 | 口令 | 线索来源 |
| --- | --- | --- |
| 保险箱 | `99.4`（或 994） | 桌面便签「守了七年的频率」、未寄出的信、99.4 停播通告 |
| 广播站机房 BIOS | `chaosheng9`（潮声9 / cs9） | 聊天里老周、机房检修日志、第九夜录音稿 |
| 警务内网 | `LW-1999` | 老周提示、1999 海难报道事故编号 |

## 五、四条证据链 → 六个结局（全部由线索决定）

聊天里「明月如霜（记者）」是唯一的**结案提交入口**。每条结论都设了线索前置门槛：**只有你访问过对应证据链的页面，这条结论才会作为选项出现**。也就是说，你「能提交什么」= 你「掌握了什么」。

| 结局 | 需要的线索（须全部访问过） | 说明 |
| --- | --- | --- |
| 一 · 官方结论 | 无（开局即有） | 放弃深究的默认浅结局 |
| 二 · 一知半解 | `1999海难报道` + `海事调查报告` | 海难链 |
| 三 · 指认瀚洋 | `瀚洋专访` + `资助协议` + `维基·听潮会` | 资金链 |
| 四 · 频率之下 | `白噪计划备忘录` + `第九夜录音稿` + `维基·次声波` | 实验链 |
| 五 · 第九夜 | `渔港监控` + `播音室监控` + `沈砚日记(后半)` | 那一夜链 |
| **真结局 · 把声音还给大海** | `白噪计划备忘录`+`资助协议`+`渔港监控`+`第九夜录音稿`+`瀚洋7号名单`+`沈砚日记(后半)` | 横跨四条链、共 6 条核心线索 |

> 机制说明：运行时用 `sessionStorage` 记录「本会话访问过的页面」当作线索；聊天选项的 `requires` 会检查这些访问记录，缺任何一条线索，对应结论就不会显示。所以想拿到真结局，必须把四条证据链的关键页面**都点进去看过**——而不是在某一步「选对答案」。

## 六、通关最短路径（攻略 · 剧透）

桌面 → 读信 → 打开聊天看老周（拿到 chaosheng9 / 99.4 / LW-1999 三个提示）→
进保险箱(`99.4`)看第九夜录音稿、沈砚日记(后半)、名单 →
进机房(`chaosheng9`)看白噪计划、资助协议、渔港/播音室监控 →
看维基(听潮会/次声波)、读瀚洋专访 → 回到聊天找「明月如霜」，此时六个结论中你**已解锁的那几个**会自动出现在选项里，其中最重的一条即真结局。

> 注：6 条核心线索被"防旁路"锁在保险箱与机房两道密码门后，搜索/论坛/新闻里的相关入口只会把你引到锁前，**必须输口令**才拿得到——想拿真结局，两道锁都得开。完整分步路线见《白噪1999-完整攻略.md》。
