# 《白噪 · 1999 蓝湾镇回声事件》剧本设计与说明

一个大型原创 ARG：**102 个页面、8 类拟真界面、10 层密码、4 道锁、9 个结局（含打破第四面墙的 ARG 结局）**。
核心机制：**结局不取决于你点了哪个选项，而取决于你解出并真正掌握的线索；证据不全，只会冤枉错的人。**
ARG 层：玩家要动**真的浏览器**——地址栏加 `#firstlight`、查真的元素周期表、用转换器解二进制、把整页倒过来读、拿真实经纬度去地图上找那片海。

## 一、导入方式（30 秒）

1. 启动编辑器：项目目录里运行 `npm run dev`（或双击 `一键启动-Windows.bat`）。
2. 浏览器打开 `http://localhost:5173/`。
3. 点「导入」，选择本目录 `examples/白噪1999-蓝湾镇回声事件.arg-blueprint.json`。
4. 点「自检」应为 0 错误 0 警告；点「预览运行」从「序章·开机」开始游玩。
5. 发布：点「导出 ZIP」得到纯静态 HTML；或直接跑 `node sync-site.mjs`（构建→回归→导出→推送 GitHub Pages）。

## 二、故事梗概

2003 年冬。你是声音修复师 **沈知微**。哥哥 **沈砚** 是沿海小镇「蓝湾」深夜电台 FM99.4《潮声》主持人，2000 年 3 月 14 日「出海遇难、尸骨无存」。你收到他遗留的旧主机和一封信。

真相：广播站总工程师 **柯振** 与「瀚洋集团」董事长 **韩启昌** 合作，用深夜广播循环植入 **4.5Hz 次声波（"白噪"）**，经由民间组织 **听潮会** 把孤儿、康复者、负债工「招募—镇静—引渡」，在暴风雨夜送上「瀚洋 7 号」，对外称海难。沈砚察觉后私录最后一期《潮声·第九夜》，因此被列入名单灭口。

## 三、页面结构（85 页）

- **枢纽**：序章·开机、桌面、加密聊天、千禧搜索、蓝湾潮声论坛(BBS)、镇档案馆(目录)、维基百科(枢纽)、4 道密码锁、3 个文件柜。
- **线索页**：新闻 9 篇、论坛帖 11 个、维基词条 6 个、卷宗档案 16 份、日记书信 5、录音/监控/日志 4、密码题与隐藏层 8、伪造证据 2、氛围页若干、结局 8。
- 拟真界面：桌面图标、搜索命中、BBS 热帖、匿名聊天、密码锁（后台×3 / BIOS）、文件夹、CRT 监控、杂志/卷宗/日记/黑客数据流版式、报纸头版 / 结案书 / CRT 黑屏三种结局版式。

## 四、密码链（6 层 · 母词是 `tide`）

| --- | --- | --- | --- |
| ① | 凯撒·退三格 | 磁带标签 `WLGH` 每字母退 3 位 | `tide`（保险箱） |
| ② | Base64 | 工程便签 `Y2hhb3NoZW5nOQ==`，控制台 `atob()` | `chaosheng9`（机房） |
| ③ | 摩尔斯 | 接线员口哨 `.-.. .-- .---- ----. ----. ----.`（仅 4 字母对照） | `lw1999`（警务内网） |
| ④ | 组合锁 | 铭牌"一九六二" ＋ ①的词 | `1962tide`（灯塔顶层） |
| ⑤ | 十六进制隐写 | 保险箱内被遮蔽的 `7374696c6c68657265`→字符 | `stillhere`（搜索→浮标信标） |
| ⑥ | 维吉尼亚 | 密信 `NVGIKBRA`，钥匙=① `tide` | `undertow`（搜索→暗流记录） |

## 五、结案＝指认嫌疑人 → 八个结局

「明月如霜（记者）」是唯一结案入口，共 12 个选项：2 个无门槛（放弃/指认版主）、**2 个伪造证据陷阱**（看了伪造的"不在场证明/守夜人手记"才会出现，全通向误判）、4 条支线结局、2 条推理问答（手法/动机，仅复述不跳转）、真结局与隐藏结局。

| 结局 | 需要的线索 |
| --- | --- |
| 官方结论 / 误判 | 无（误判含 2 个伪造证据陷阱） |
| 一知半解 | `1999海难报道` + `海事调查报告`（公开可达） |
| 指认瀚洋 | `瀚洋专访` + `资助协议` + `维基·听潮会` |
| 频率之下 | `白噪计划备忘录` + `第九夜录音稿` + `维基·次声波` |
| 第九夜 | `渔港监控` + `播音室监控` + `沈砚日记(后半)` |
| **真结局·把声音还给大海** | **9 条核心线索**（跨三道锁，见下） |
| **隐藏结局·潮声未绝** | 真结局 9 条 + `浮标信标` + `暗流记录` |

**9 条核心线索**：`白噪计划备忘录` `资助协议` `渔港监控` `第九夜录音稿` `瀚洋7号名单` `沈砚日记(后半)`（保险箱+机房）＋ `守塔人日志` `原始声学数据`（灯塔顶层）＋ `出港夜气象原始记录`（档案馆）。
防旁路：断掉三道锁，10/10 核心线索不可达——**必须解题**。

## 六、通关最短路径（剧透）

序章进桌面 → 读信 → 「磁带标签」解凯撒得 `tide` → 开保险箱（录音稿/日记后半/名单 + 隐写带子）→ 「工程便签」解 Base64 得 `chaosheng9` → 开机房（白噪计划/资助协议/两路监控）→ 「灯塔铭牌」组合 `1962tide` 开顶层（守塔人日志/原始声学数据/维吉尼亚密信）→ 搜「气象」读气象原始记录 → 补瀚洋专访/听潮会/次声波/内刊演讲/船检底档 → 聊天「明月如霜」→ 推演手法与动机 → 指认真凶柯振＝真结局。
隐藏结局：`stillhere`→浮标信标；维吉尼亚解出 `undertow`→暗流记录；再回聊天。完整分步见《白噪1999-完整攻略.md》。

## 七、站主专用

- 隐藏「监听终端」（实时 PV/UV）：游戏内搜索 `994stats`（`994starts` 亦可）；或直接访问 `abacus.jasoncameron.dev/get/bluebay-echo-1999/pages` 与 `/visitors`。
- 一键同步：`node sync-site.mjs "提交说明"`（构建→回归→导出→推送）；双击 `一键同步.bat`。
- 彩蛋：序章左下「◍ 白噪」开关 = Web Audio 实时合成的 4.5Hz 拍频低噪。
