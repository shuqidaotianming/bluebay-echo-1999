# 《白噪 · 1999 蓝湾镇回声事件》剧本设计与说明

一个大型原创 ARG：**60 个页面、8 类拟真界面、3 道密码题、8 个结局**。
核心机制：**结局不取决于你点了哪个选项，而取决于你在整台电脑里真正挖到了哪几条线索。**

## 一、导入方式（30 秒）

1. 启动编辑器：项目目录里运行 `npm run dev`（或双击 `一键启动-Windows.bat`）。
2. 浏览器打开 `http://localhost:5173/`。
3. 点右上角「导入」，选择本目录 `examples/白噪1999-蓝湾镇回声事件.arg-blueprint.json`。
4. 点「自检」应为 0 错误 0 警告；点「预览运行」即可从「沈砚遗留的主机」开始游玩。
5. 想发布给别人：点「导出 ZIP」，得到纯静态 HTML，扔到任意静态托管即可。

> 同目录的 `build-blueprint.mjs` 是生成脚本。想改文案 / 加页面 / 调结局门槛，改完运行 `node build-blueprint.mjs` 会重新生成蓝图并自动自检。

## 二、故事梗概

2003 年冬。你是声音修复师 **沈知微**。哥哥 **沈砚** 是沿海小镇「蓝湾」深夜电台 FM99.4《潮声》主持人，2000 年 3 月 14 日「出海遇难、尸骨无存」。你收到他遗留的旧主机和一封信。

真相：广播站总工程师 **柯振** 与「瀚洋集团」董事长 **韩启昌** 合作，用深夜广播循环植入 **4.5Hz 次声波（"白噪"）**，经由民间组织 **听潮会** 把孤儿、康复者、负债工「招募—镇静—引渡」，在暴风雨夜送上「瀚洋 7 号」，对外称海难。沈砚察觉后私录最后一期《潮声·第九夜》，因此被列入名单灭口。

## 三、页面结构（60 页）

- **枢纽**：桌面、加密聊天、千禧搜索、蓝湾潮声论坛(BBS)、镇档案馆(目录)、维基百科(枢纽)、3 处密码锁、2 个文件柜。
- **线索页**：新闻 8 篇、论坛帖 8 个、维基词条 5 个、卷宗/日记/录音稿/名单/监控等 12+ 页、密码题与隐藏层 5 页、结局 8 页。
- 每类拟真界面都用到了：桌面图标、搜索关键词命中、BBS 热帖、匿名聊天、密码锁（后台 / BIOS）、文件夹、CRT 监控、杂志/卷宗/日记/黑客数据流版式、以及报纸头版 / 结案书 / CRT 黑屏三种结局版式。

## 四、三把口令＝三道密码题（不再有任何明文答案）

| 锁 | 谜题 | 解法 | 答案 |
| --- | --- | --- | --- |
| 保险箱 | 凯撒·退三格 | 磁带标签 `WLGH` 每字母退 3 位 | `tide` |
| 机房 BIOS | Base64 | 工程便签里的 `Y2hhb3NoZW5nOQ==`，控制台 `atob()` | `chaosheng9` |
| 警务内网 | 摩尔斯 | 接线员口哨 `.-.. .-- .---- ----. ----. ----.` | `lw1999` |
| 隐藏层 | 十六进制隐写 | 保险箱内被遮蔽的 `7374696c6c68657265`→字符 | `stillhere`（再搜索） |

> 保险箱认字母不认数字，`99.4` 只是频率、不是口令。三处明文泄露点已全部清除。

## 五、结案＝指认嫌疑人 → 八个结局（线索决定能否指对）

聊天里「明月如霜（记者）」是唯一结案入口。**不开锁最多只能到"官方结论 / 误判 / 一知半解"这类浅结局**（前两者无门槛；"一知半解"只需公开报道即可触发）；指认瀚洋、频率之下、第九夜、真结局、隐藏结局都需要先解密码开锁取线索。

| 结局 | 需要的线索（须全部访问过） |
| --- | --- |
| 官方结论 | 无（开局即有·放弃） |
| 误判（坏结局） | 无（证据不全时的陷阱） |
| 一知半解 | `1999海难报道` + `海事调查报告` |
| 指认瀚洋 | `瀚洋专访` + `资助协议` + `维基·听潮会` |
| 频率之下 | `白噪计划备忘录` + `第九夜录音稿` + `维基·次声波` |
| 第九夜 | `渔港监控` + `播音室监控` + `沈砚日记(后半)` |
| **真结局·把声音还给大海** | 6 条核心线索（须解凯撒+Base64 开两道锁） |
| **隐藏结局·潮声未绝** | 真结局 6 条 + `浮标信标`（须再解隐写） |

> 机制：运行时用 `sessionStorage` 记录访问过的页面当线索；选项 `requires` 缺任一条线索就不显示。6 条核心线索被"防旁路"锁在两道密码门后，搜索/论坛只把你引到锁前，**必须先解密码题**才拿得到。

## 六、通关最短路径（剧透）

桌面读信 → 看「磁带标签」解凯撒得 `tide` → 开保险箱读 录音稿/日记后半/名单（+点开隐写带子）→ 搜「便签」解 Base64 得 `chaosheng9` → 开机房读 白噪计划/资助协议/渔港监控/播音室监控 → 补 瀚洋专访/听潮会/次声波 → 聊天找「明月如霜」→ 指认真凶柯振＝真结局。
隐藏结局：把隐写带子解出的 `stillhere` 拿去搜索 → 打开「浮标信标」→ 回聊天多出的选项＝隐藏结局。完整分步见《白噪1999-完整攻略.md》。
