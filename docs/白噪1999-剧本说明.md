# 《白噪 · 1999 蓝湾镇回声事件》剧本设计与说明

一个大型原创 ARG：**200 个页面、8 类拟真界面、13 层谜题、6 道锁、7 处对话校验、10 个结局（含打破第四面墙的 ARG 结局与「名字墙」纪念结局）**。
核心机制：**结局不取决于你点了哪个选项，而取决于你解出并真正掌握的线索；证据不全，只会冤枉错的人。**
ARG 层：玩家要动**真的浏览器**——地址栏加 `#firstlight` 与 `#sixtysix`、查真的元素周期表、用转换器解二进制、把整页倒过来读、拿真实经纬度查省份与潮汐周期，再把答案**打字发给联系人**校验。

## 一、导入方式（30 秒）

1. 启动编辑器：项目目录里运行 `npm run dev`（或双击 `一键启动-Windows.bat`）。
2. 浏览器打开 `http://localhost:5173/`。
3. 点「导入」，选择本目录 `examples/白噪1999-蓝湾镇回声事件.arg-blueprint.json`。
4. 点「自检」应为 0 错误 0 警告；点「预览运行」从「序章·开机」开始游玩。
5. 发布：点「导出 ZIP」得到纯静态 HTML；或直接跑 `node sync-site.mjs`（构建→回归→导出→推送 GitHub Pages）。

## 二、故事梗概

2003 年冬。你是声音修复师 **沈知微**。哥哥 **沈砚** 是沿海小镇「蓝湾」深夜电台 FM99.4《潮声》主持人，2000 年 3 月 14 日「出海遇难、尸骨无存」。你收到他遗留的旧主机和一封信。

真相：广播站总工程师 **柯振** 与「瀚洋集团」董事长 **韩启昌** 合作，用深夜广播循环植入 **4.5Hz 次声波（"白噪"）**，经由民间组织 **听潮会** 把孤儿、康复者、负债工「招募—镇静—引渡」，在暴风雨夜送上「瀚洋 7 号」，对外称海难。沈砚察觉后私录最后一期《潮声·第九夜》，因此被列入名单灭口。

## 六、通关最短路径（剧透）

序章进桌面 → 读信 → 「磁带标签」解凯撒得 `tide` → 开保险箱（录音稿/日记后半/名单 + 隐写带子）→ 「工程便签」解 Base64 得 `chaosheng9` → 开机房（白噪计划/资助协议/两路监控 + 频率手记）→ 「灯塔铭牌」组合 `1962tide` 开顶层（守塔人日志/原始声学数据/维吉尼亚密信/伪造不在场证明）→ 搜「气象」读气象原始记录 → 补瀚洋专访/听潮会/次声波/内刊演讲/船检底档/呼号/元素船名 → 聊天「明月如霜」→ 推演手法与动机 → 指认真凶柯振＝真结局。
隐藏结局：`stillhere`→浮标信标；维吉尼亚解出 `undertow`→暗流记录；再回聊天。
ARG 结局：在「频率手记」页地址栏加 `#firstlight`；用周期表解出 `blackfin` 并搜索；集齐后回聊天，选"把电台重新接回天线"。
名字墙结局：档案馆「沿着名单往下走」集齐 14 份遗物/证言，回聊天选"用整个头版，只印名字"。
二周目：藏头诗开记者信箱（兄妹双线）；`1962undertow` 开港务深层；7 位联系人的问答集齐身世档案；真结局后进入「一年后」。完整分步见《白噪1999-完整攻略.md》。
