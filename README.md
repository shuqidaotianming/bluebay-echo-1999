# 白噪 · 1999 蓝湾镇回声事件

> 一个大型原创 ARG 风格桌面解谜游戏：**60 个页面 · 3 道密码题 · 8 个结局**。
> 结局不取决于你点了哪个选项，而取决于你解出并掌握了哪几条线索——不解题，只能"放弃"或"冤枉好人"。

## 在线试玩

这是一个纯静态站点，无需服务器。直接访问本仓库的 GitHub Pages，或把整个仓库下载到本地用浏览器打开 `index.html` 即可游玩（建议用本地静态服务器以保证 `sessionStorage` 线索进度在各浏览器一致，例如 `npx serve .`）。

## 玩法速览

- 你是声音修复师**沈知微**，追查失踪的电台主持人哥哥**沈砚**。
- 在「桌面 / 加密聊天 / 千禧搜索 / 蓝湾潮声论坛 / 档案馆 / 维基 / 保险箱 / 机房」之间搜集线索。
- 每打开一个页面即记为一条"线索"。聊天里记者「明月如霜」是唯一结案入口——**结案＝指认嫌疑人**，能指谁、指得对不对，取决于你凑齐了哪些能互相咬合的证据。
- **三把口令＝三道密码题**（不再有任何明文答案）：保险箱要解**凯撒**（`WLGH`→退三格→`tide`）、机房要解**Base64**（`atob(...)`→`chaosheng9`）、警务内网要解**摩尔斯**（→`lw1999`）。
- 6 条核心线索被"防旁路"锁在两道密码门后：**不解开凯撒 + Base64，就拿不到真结局**；再解一层十六进制隐写，可开启隐藏结局。

## 目录结构

```
.
├── index.html            # 游戏入口（桌面）
├── *.html                # 其余 59 个页面（含 3 道密码题页、隐写页、浮标信标页、8 个结局页）
├── arg-runtime.js        # 线索记录与路由运行时
├── arg-blueprint.json    # 完整剧情蓝图（可导入 ARG-Blueprinter 再编辑）
├── assets/cover.png      # 作品封面
├── docs/                 # 剧本说明 + 完整攻略（含密码题答案·剧透）
└── source/blueprint.json # 蓝图源文件（同 arg-blueprint.json）
```

## 二次创作 / 更新

用开源工具 [ARG-Blueprinter](https://github.com/GallonHong/ARG-Blueprinter) 导入 `arg-blueprint.json` 即可在可视化画布中继续编辑，改完重新导出静态站覆盖本仓库根目录即可。
